# 🚢 Titanic Survival Prediction

A beginner machine learning project using the **Titanic dataset** and **Logistic Regression** to predict whether a passenger survived.

### 🛠️ Tools
- Python
- Pandas
- NumPy
- Seaborn
- Scikit-learn
- Jupyter Notebook

### 🔄 Process
- Cleaned missing data
- Converted categorical features using dummy variables
- Split the data into training and testing sets
- Trained a Logistic Regression model
- Made predictions on the test data
- Evaluated the model using a confusion matrix, accuracy, and classification report

### 📊 Result

**Accuracy: 77.1%**

### 🧠 What I Learned

This project helped me understand **data preprocessing, feature engineering, train/test splitting, Logistic Regression, predictions, and model evaluation**.
